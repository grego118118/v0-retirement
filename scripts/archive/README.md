# Archived Scripts

This directory contains test, debug, and validation scripts that were previously in the repository root.

## Contents

These scripts were used during development for testing, debugging, and validating various features. They are preserved for reference but may not work without modification.

## Categories

### Test Scripts (`test-*.js`, `test-*.mjs`)
- Unit and integration test scripts for various features
- API endpoint testing
- Calculation validation tests
- UI component testing

### Debug Scripts (`debug-*.js`)
- Debugging utilities for troubleshooting issues
- Database inspection scripts
- Subscription flow debugging

### Validation Scripts (`validate-*.js`, `verify-*.js`)
- MSRB calculation validation
- Option C factor verification
- Database schema verification

### Analysis Scripts (`analyze-*.js`)
- Runtime vs build-time analysis
- Calculation discrepancy analysis
- Group 4 Option C pattern analysis

### Monitor Scripts (`monitor-*.js`)
- Deployment monitoring
- Database restoration monitoring
- Build success monitoring

### Setup Scripts (`setup-*.js`)
- Blog system setup
- Database setup utilities
- AI blog system configuration

### HTML Test Files (`*.html`)
- Browser-based test pages
- Visual testing utilities
- Fix verification pages

### MJS Test Files (`*.mjs`)
- PDF generation testing
- ES module-based tests

## Usage

These scripts may require environment variables or database access to run.
Most were designed for one-time use during development and debugging.

## Note

Active scripts are located in `/scripts/` and `/scripts_app/`.
Jest tests are in `/__tests__/` directory.
